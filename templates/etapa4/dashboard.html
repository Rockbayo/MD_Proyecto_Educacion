Instrucciones para abrir el informe localmente

  1. Descarga el archivo EduMetrics_Etapa4.pbix con el botón "Descargar PBIX" o desde el repositorio.
  2. Abre el archivo con Power BI Desktop (versión ≥ 2.120, gratuita en Microsoft Store).
  3. En Inicio → Transformar datos, actualiza la ruta de la fuente al archivo CSV local:
    data/processed/saber11_integrado_comprimido.csv
  4. Haz clic en Actualizar. El archivo muestreado (5%, 227 K registros) es suficiente para exploración.
  5. Para el informe con datos completos (761 K post-ETL), conecta al servidor SQL Server Staging (ver Etapa 3).

⚠ Si el PBIX supera 100 MB, se proporciona enlace de descarga externo en el README del repositorio.
