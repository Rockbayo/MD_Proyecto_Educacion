¿CÓMO INSERTAR TU INFORME DE POWER BI?

  1. Abre tu archivo .pbix en Power BI Desktop.
  2. Haz clic en Inicio → Publicar y selecciona tu área de trabajo en Power BI Service.
  3. En Power BI Service, ve a Archivo → Insertar informe → Publicar en la web (público).
  4. Copia el enlace del <iframe src="..."> generado.
  5. Reemplaza POWERBI_EMBED_URL_AQUI en este template con dicho enlace.

GUÍA Instrucciones para Abrir y Actualizar el Archivo PBIX

1. REQUISITOS

Power BI Desktop (versión 2023 o superior). Acceso al dataset post-ETL en formato SQL Server o CSV exportado.

2. ACTUALIZACIÓN DE DATOS

En Power BI Desktop: clic en Inicio → Transformar datos → Configuración de origen de datos y actualizar la ruta al servidor o archivo local.

3. REFRESCAR MODELO

Presionar Inicio → Actualizar. Las medidas DAX y las relaciones entre tablas se recalculan automáticamente sin alterar los tableros.
